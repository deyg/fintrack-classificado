## Decisão aplicada (DEC-ERR-005)

- **400**: JSON malformado, corpo vazio ou `null`, tipo errado (`name: 123`), propriedade desconhecida.
- **422**: nome ausente/nulo/vazio/branco/com mais de 100 caracteres; natureza ausente ou fora de `INCOME`/`EXPENSE` (inclusive minúscula).
- Problem Details (`application/problem+json`) com `type` `https://httpstatuses.com/<status>`.
- Premissa: propriedade obrigatória ausente é 422 (regra de valor), não 400.
- 409 é declarado no contrato, mas não ocorre: não existe regra de unicidade de nome.

## Aceite

- 201, Location, JSON no schema `Category` (conjunto exato de propriedades) e persistência real conferida no SQL Server.
- 400/422 documentados no contrato e testados; requisição inválida não persiste nada.
- A Api não toca `DbContext` nem Domain (arquitetura verde); apenas Application no endpoint.
