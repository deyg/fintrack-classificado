## Regras e códigos

- 201 + `Location: /api/v1/transactions/{id}`.
- 409: conta inativa (RN09).
- 422 (valores): conta inexistente (`accountId`; o contrato não declara 404 em `createTransaction`), campo obrigatório ausente, valor ≤ 0, mais de 2 casas, valor acima de `decimal(18,2)`, descrição > 500, data futura (`realizedAt`, RN07).
- 400 (DEC-ERR-005): JSON malformado, tipo errado (inclui data inválida), propriedade desconhecida, corpo vazio.
- Natureza do lançamento não é gravada nem aceita: deriva da categoria da conta (RN08).
- Data de hoje = `TimeProvider.GetLocalNow()` (fuso local do servidor); data de hoje é aceita, amanhã é rejeitada.

## Pendências e riscos

- O fuso para "hoje" não foi decidido formalmente; adotado o fuso local do servidor. Registrado como risco para revisão humana (sem mudança de contrato).
- O limite máximo de valor (`decimal(18,2)`) é validado como 422; o contrato não declara `maximum`.
- Corrida entre desativação da conta e criação do lançamento não é serializada.
