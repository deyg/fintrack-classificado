## Mudança implementada

Handler explícito, sem MediatR: valida → traduz natureza → `Category.Create` → `ICategoryRepository.AddAsync` → `CategoryResult` com natureza externa. Comando inválido não chama o repositório. Token de cancelamento é propagado ao repositório e um token já cancelado interrompe antes de qualquer trabalho. Erros usam os nomes de campo do contrato (`name`, `nature`). A natureza aceita só `INCOME`/`EXPENSE` em maiúsculas, como o enum do contrato.

A Api ainda **não** chama `AddApplication()`: o handler depende de `ICategoryRepository`, sem implementação até CAT-003, e a validação de DI em Development falharia. O registro entra na composição junto com a Infrastructure em CAT-003.

Fora de escopo: mapeamento HTTP (400 vs 422, DEC-ERR-005, decidido em CAT-004), persistência, endpoint.
